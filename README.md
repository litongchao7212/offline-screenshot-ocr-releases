# Offline Screenshot OCR

离线高精度截图OCR是一款 Windows 本地截图 OCR、表格复制、审校与钉图标注工具。OCR 默认在本机完成；在线 OCR、翻译和 AI 校核仅在用户主动配置并调用时联网。

## 当前版本

当前正式版：`0.8.7`

主要更新：

- 修复第二屏、负坐标显示器和混合缩放下的钉图工具栏偏移。
- 文字标注支持一个字位起始输入、点击空白提交、同步缩放和背景样式。
- 钉图工作区保存标注、四类独立序号、窗口状态和 OCR 图层设置。
- 支持异常退出恢复、工作区备份恢复和显示器断开后归位。
- 剪贴板写入改为异步队列，持续占用时不阻塞界面。
- 增加连续截图、资源增长、启动预算和安装升级数据保护门禁。

## 下载

从 [Releases](https://github.com/litongchao7212/offline-screenshot-ocr-releases/releases/latest) 下载最新安装包。

本地生成的安装包名为：

`Offline Screenshot OCR-0.8.7-Setup.exe`

GitHub Release 会强制把资产名中的空格规范化为点号，因此 GitHub 实际下载资产为：

`Offline.Screenshot.OCR-0.8.7-Setup.exe`

两者文件内容、大小和 SHA256 完全相同。下载后请用仓库中的 `SHA256.txt` 核对完整性。

## 更新方式

程序每天最多自动检查一次签名更新清单，也可手动检查。发现新版后只提示并打开 GitHub Release 页面，不会静默下载或安装。
