# Offline Screenshot OCR

离线高精度截图 OCR 是一款 Windows 本地截图 OCR、表格复制、审校与钉图标注工具。OCR 默认在本机完成；在线 OCR、翻译和 AI 校核仅在用户主动配置并调用时联网。

## 当前版本

当前正式版：`0.8.8`

主要更新：

- 画笔新增五种线型，箭头扩展为六种样式，矩形/圆形支持独立边线色与填充色。
- 高亮默认采用淡黄色宽幅 Mark 笔，马赛克支持像素和磨砂两种方式。
- 橡皮擦支持对象、笔刷、框选和可撤销清屏，并修正矢量图形局部擦除。
- 脱敏规则库支持关键词、字段标签、正则、表格列和白名单。
- OCR 工具改为固定单行按钮栏，暗色 CAD 低产出时自动尝试增强识别。
- “选择并拖动”状态锁定所有标注和 OCR 图层，避免误移动图元。

## 下载

从 [Releases](https://github.com/litongchao7212/offline-screenshot-ocr-releases/releases/latest) 下载最新安装包。

本地生成的安装包名为：

`Offline Screenshot OCR-0.8.8-Setup.exe`

GitHub Release 会将资产名中的空格规范化为点号，因此实际下载资产为：

`Offline.Screenshot.OCR-0.8.8-Setup.exe`

两者文件内容、大小和 SHA256 完全相同。下载后请用仓库或 Release 中的 `SHA256.txt` 核对完整性。

## 更新方式

程序每天最多自动检查一次签名更新清单，也可手动检查。发现新版后只提示并打开 GitHub Release 页面，不会静默下载或安装。
