# Offline Screenshot OCR

离线高精度截图OCR是一款Windows本地截图OCR与审校工具。OCR识别默认在本机完成；在线OCR、翻译和AI校核仅在用户主动配置并调用时联网。

## 当前版本

当前正式版：`0.8.1`

0.8.1主要更新：

- 新增快速文字、精确文字、表格直粘、仅复制图片、打开审校五种截图后动作方案。
- 每种方案独立控制识别模式、small/medium模型、自动复制、结果窗口和超时。
- 普通文字区单击或移动光标时整行高亮，选择态支持跨行和自动换行片段。
- “常规”和“截图与历史”合并为紧凑单页。
- 修复安装器错误限制Windows 11的问题，已通过Windows 10 22H2 x64真机验收。

## 更新方式

程序每天最多自动检查一次签名更新清单，也可手动检查。发现新版后只提示并打开GitHub Release页面，不会静默下载或安装。
