# Offline Screenshot OCR

离线高精度截图OCR是一款Windows 11 x64本地截图OCR与审校工具。OCR识别默认在本机完成；在线OCR、翻译和AI校核仅在用户主动配置并调用时联网。

## 当前版本

当前正式版：`0.8.0`

0.8.0新增可信审校核心：

- Result IR v2统一文字块、文字行、表格单元格、来源坐标、置信度、编辑锚点和编辑状态。
- 兼容迁移0.7.x会话与历史，不清除现有设置、授权、历史和截图。
- 待复核队列覆盖低置信度文字、金额、日期、百分比、长编号、前导零编号及表格异常。
- 点击风险可定位原图文字框或表格单元格；风险只提示，不自动修改识别结果。

## 下载

从[Releases](https://github.com/litongchao7212/offline-screenshot-ocr-releases/releases)下载：

`Offline Screenshot OCR-0.8.0-Setup.exe`

安装包在本机与GitHub使用完全相同的英文文件名。下载后请用仓库中的`SHA256.txt`核对完整性。

## 更新方式

程序每天最多自动检查一次签名更新清单，也可手动检查。发现新版后只提示并打开GitHub Release页面，不会静默下载或安装。
